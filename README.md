# Flower Salon Network

Курсова робота: інформаційна система мережі салонів квітів.

## Stack
- Backend: Python + FastAPI
- ORM: SQLAlchemy 2.x
- Database: PostgreSQL
- Frontend: React + Vite
- UML: diagrams.net XML (`docs/uml`)

## Planned GoF patterns
- Builder — custom bouquet creation
- Strategy — delivery and discount calculation
- Decorator — bouquet add-ons / packaging
- State — order status lifecycle
- Observer — user notifications
